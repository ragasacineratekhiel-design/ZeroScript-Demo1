# ZeroScript V2 × Roblox Studio Agent — All AI + Claude (v2.3.0)

> **Install:** `chrome://extensions` → Developer mode → **Load unpacked** → select **`zeroscript-extension-v2/`** in this repo. You should see card title **ZeroScript V2 × Roblox Studio Agent 2.3.0**.

This repo serves **ZeroScript V2** (Claude + 14 AI sites). GitHub `main` is now V2 — if you saw the old single-version, hard-refresh (Ctrl+Shift+R) and re-load the root `zeroscript-extension-v2` folder.

- **Folder to load:** `zeroscript-extension-v2/` (root) — same as `ZeroScript Demo/ZeroScript-Free-1.5.5/zeroscript-extension/` but without the spaced path.
- Supports: chat.deepseek.com, chatgpt.com, gemini.google.com, **claude.ai**, kimi.ai, chat.z.ai, chat.qwen.ai, arena.ai, meta.ai, perplexity.ai, copilot.microsoft.com, grok.com, poe.com, chat.mistral.ai
- Full Studio control: scripts, explorer, assets, Play mode start/stop, all game settings/services
- Bridge: `start.bat` / `MacOS_Start.command` → enable **Studio as MCP Server** in Studio first

See `zeroscript-extension-v2/README.md` for full docs.
